# Statement of Applicability

This folder contains the Statement of Applicability (SoA) and supporting documentation used to demonstrate the applicability and implementation status of information security controls within the ISMS.

## Coverage

- Statement of Applicability
- Annex A control applicability assessment
- Control justification
- Control implementation status
- Control ownership
- Supporting implementation evidence

## Purpose

The Statement of Applicability provides a structured record of the information security controls considered within the ISMS and the justification for their inclusion or exclusion.

## Control Framework

The project uses the ISO/IEC 27001:2022 Annex A control structure as the reference framework for the applicability assessment.

## Evidence

Supporting SoA documentation and control evidence are maintained within the relevant project folders.
