# ISO/IEC 27001:2022 ISMS Implementation & GRC Portfolio

## Project Overview

This portfolio demonstrates a practical approach to designing and documenting an Information Security Management System (ISMS) aligned with ISO/IEC 27001:2022.

The project covers ISMS governance, organizational context, information security risk management, Statement of Applicability (SoA), Annex A control implementation, operational security processes, incident management, access management, business continuity, disaster recovery, audit readiness and continual improvement.

> **Portfolio Disclaimer:** This is a demonstration and learning portfolio project. It is not a claim of ISO/IEC 27001 certification, accreditation, or an actual external audit.

---

## Project Objectives

- Demonstrate practical understanding of ISO/IEC 27001:2022
- Develop structured ISMS documentation
- Establish an information security risk management process
- Develop and maintain a risk register
- Develop a Statement of Applicability (SoA)
- Map applicable Annex A controls to security requirements
- Document operational information security processes
- Establish audit-oriented evidence structures
- Demonstrate business continuity and disaster recovery planning
- Demonstrate continual improvement activities
