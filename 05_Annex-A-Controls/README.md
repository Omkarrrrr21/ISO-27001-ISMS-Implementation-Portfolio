# Annex A Controls

This folder contains the Annex A control structure and supporting documentation used within the ISO/IEC 27001:2022 ISMS portfolio.

## Control Categories

### A.5 — Organizational Controls

Controls related to information security policies, roles and responsibilities, segregation of duties, management responsibilities and organizational security arrangements.

### A.6 — People Controls

Controls related to personnel security, awareness, education, training and information security responsibilities.

### A.7 — Physical Controls

Controls related to physical security, secure areas, equipment protection and physical access.

### A.8 — Technological Controls

Controls related to access management, authentication, endpoint security, vulnerability management, logging, monitoring, backup, network security and other technological safeguards.

## Purpose

To provide a structured representation of the ISO/IEC 27001:2022 Annex A control framework and its relationship with the ISMS implementation and supporting evidence.

## Control Applicability

Control applicability and justification are documented through the Statement of Applicability maintained in the dedicated SoA section of this repository.
