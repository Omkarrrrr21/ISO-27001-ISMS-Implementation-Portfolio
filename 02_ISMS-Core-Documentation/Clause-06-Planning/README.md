# Clause 6 — Planning

This folder contains documentation related to ISMS planning, information security risks and opportunities, risk treatment planning and information security objectives.

## Coverage

- Actions to address risks and opportunities
- Information security risk assessment
- Information security risk treatment
- Information security objectives
- Planning to achieve information security objectives
- Changes to the ISMS

## Purpose

To demonstrate how information security risks, opportunities and objectives are systematically planned and integrated into the ISMS.
