# Clause 7 — Support

This folder contains documentation related to the resources and support processes required to establish, implement, maintain and continually improve the ISMS.

## Coverage

- Resources
- Competence
- Awareness
- Communication
- Documented information
- Creation and updating of documented information
- Control of documented information

## Purpose

To demonstrate that the ISMS is supported by appropriate resources, competent personnel, effective communication and controlled documented information.
