# ISMS Core Documentation

This folder contains the core Information Security Management System (ISMS) documentation aligned with ISO/IEC 27001:2022 Clauses 4–10.

## Coverage

- Clause 4 — Context of the Organization
- Clause 5 — Leadership
- Clause 6 — Planning
- Clause 7 — Support
- Clause 8 — Operation
- Clause 9 — Performance Evaluation
- Clause 10 — Improvement

## Purpose

The documentation demonstrates the governance, planning, operational, performance evaluation and continual improvement components of an ISMS.
