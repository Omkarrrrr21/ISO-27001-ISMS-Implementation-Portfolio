# Clause 10 — Improvement

This folder contains documentation related to nonconformity, corrective action and continual improvement of the ISMS.

## Coverage

- Nonconformity and corrective action
- Response to identified nonconformities
- Root cause analysis
- Corrective action planning and implementation
- Effectiveness review of corrective actions
- Continual improvement of the ISMS

## Purpose

To demonstrate how identified issues are addressed and how the ISMS is continually improved based on findings, corrective actions, performance results and organizational needs.
