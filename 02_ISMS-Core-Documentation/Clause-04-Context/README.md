# Clause 4 — Context of the Organization

This folder contains documentation related to the context of the organization and the establishment of the ISMS scope.

## Coverage

- Internal and external issues relevant to the ISMS
- Interested parties and their requirements
- Determination of the ISMS scope
- Information security context
- Interfaces and dependencies relevant to the ISMS

## Purpose

To demonstrate how organizational context and interested-party requirements are considered when establishing and maintaining the ISMS.
